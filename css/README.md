# VISTA — Modern Clothing Store

Front-end fashion e-commerce demo built with HTML, CSS, JavaScript and React. Includes 50 products with prices displayed in Indian Rupees (INR).

## Project files

- `index.html` — page structure and React CDN imports
- `css/styles.css` — styling
- `js/app.js` — compiled React application and product data
- `start-local.bat` — starts a local web server on Windows

## Run on Windows

1. Extract the complete ZIP folder.
2. Keep `index.html`, `css/`, and `js/` together in the same project folder.
3. Double-click `start-local.bat` (Python must be installed), or open the folder in VS Code and use Live Server.
4. Do not open `index.html` separately from the ZIP or move it away from its `css` and `js` folders.

React and ReactDOM are loaded from CDNs, so an internet connection is required.

## Publish on GitHub Pages

Upload the contents of this folder to the repository root. In GitHub, go to **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.

## Note

This is a front-end demo. Checkout is simulated; no real payments are processed and orders are not stored in a backend.
