# VISTA — Modern Clothing Store

This project is separated into HTML, CSS and JavaScript files.

## Folder structure

- `index.html` — page structure and React CDN imports
- `css/styles.css` — all styling
- `js/app.js` — React application and product catalogue

## Run locally

Keep the folder structure unchanged. Open the project in VS Code and use the Live Server extension, or deploy the folder to Vercel/GitHub Pages with `index.html` at the project root.

An internet connection is required because React, ReactDOM and Google Fonts are loaded from CDNs.

## Note

This is a front-end demonstration. The checkout is simulated and does not process real payments or save orders to a backend.
